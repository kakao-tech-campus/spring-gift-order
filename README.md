# spring-gift-order

## STEP1 - 카카오 로그인

- [ ] **카카오 애플리케이션 설정:** Kakao Developers에서 앱을 등록하고 REST API 키와 Redirect URI를 설정한다.
- [ ] **설정 추가:** `application.properties`에 카카오 관련 키들을 안전하게 추가한다.
- [ ] **OAuth DTO 구현:** 카카오로부터 토큰 및 사용자 정보를 받기 위한 DTO를 생성한다.
- [ ] **OAuth 서비스 구현:** 인가 코드를 사용하여 카카오 서버와 통신하고, 액세스 토큰을 받아오는 로직을 구현한다.
- [ ] **기존 회원 로직과 연동:** 카카오로부터 받은 이메일로 회원을 찾거나, 신규 가입시키는 로직을 구현한다.
- [ ] **OAuth 컨트롤러 구현:** 카카오로부터 리다이렉트 요청을 받아 인가 코드를 처리하고, 최종적으로 우리 시스템의 JWT를 반환하는 API를 구현한다.
